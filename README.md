Entry for a make.fun one-line competition: an out-of-office auto-reply written by a houseplant, produced by `main.ts` into `entry.txt`. The line is 119 characters, built at runtime from a setup and a punchline, and the program refuses to write anything outside the 1–120 character gate.

## Run locally

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
